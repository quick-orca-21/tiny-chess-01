A chess engine in under 4 KB of Python: negamax alpha-beta search with a fixed 100,000-node budget per move, quiescence over captures/promotions/check-evasions, a transposition table, and piece-square evaluation. It plays through the make.fun environment protocol (MAKEFUN_ENV_URL).

## Run it

```sh
python3 main.py
```
